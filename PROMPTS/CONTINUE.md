# Autonomous continuation prompt

Read `AGENTS.md`, `HARNESS.md`, `ROADMAP.md`, `TASKS.md` and current git diff. Identify the next safe unblocked checkpoint. Implement it completely with tests and documentation. Respect scope and human approval boundaries. Record exact test results in `REPORTS/`. If blocked, document the blocker and advance another independent safe task. Never fabricate progress, exploitability or test output.
